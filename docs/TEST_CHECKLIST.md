# Checklist ทดสอบระบบ IP.UC Performance Analytics Dashboard

ใช้หลังติดตั้งจริงบน GitHub Pages + Google Apps Script
ทำเครื่องหมาย `[x]` เมื่อผ่าน และบันทึกวันที่/ผู้ทดสอบไว้ท้ายเอกสาร

> เตรียมบัญชี Google อย่างน้อย 5 บัญชี: `SUPER_ADMIN` (อีเมลใน BOOTSTRAP_SUPER_ADMIN_EMAIL), `ADMIN`, `EDITOR`, `VIEWER` และบัญชีใหม่ที่ยังไม่สมัคร
> หลังทดสอบแต่ละข้อ ตรวจชีต **AuditLogs** ว่ามีเหตุการณ์ตรงตามที่ระบุ

## 0. ก่อนเริ่ม

- [ ] เปิด URL ของ Web App (`.../exec`) ใน Browser แล้วเห็น `"message":"IP.UC API พร้อมใช้งาน"`
- [ ] รัน `checkConfiguration()` ใน Apps Script แล้ว GOOGLE_CLIENT_ID และ BOOTSTRAP_SUPER_ADMIN_EMAIL ขึ้น “ตั้งค่าแล้ว”
- [ ] Google Sheets มีชีต `Users`, `Data`, `ImportLogs`, `AuditLogs`, `Settings` พร้อม Header ครบ
- [ ] หน้าเว็บไม่มีป้าย “โหมดข้อมูลตัวอย่าง” (แปลว่าตั้งค่า `GAS_API_URL` ถูกต้อง)
- [ ] เปิด DevTools → Console ไม่มี error สีแดง (ยกเว้นคำเตือนของ Google Sign-In เรื่อง FedCM)

## 7. ข้อมูลผิดพลาด (ใช้ `samples/test_invalid_rows.csv`)

- [ ] ระบบหาแถวหัวตารางเจอ แม้มีแถวชื่อรายงานอยู่ด้านบน (Header อยู่แถว 2)
- [ ] ไม่ผ่าน 5 แถว พร้อมเลขแถวและเหตุผล: ซ้ำในไฟล์ (แถว 4), เดือน 6913 (แถว 5), ไม่มีงวด STM (แถว 6), “abc” ไม่ใช่ตัวเลข (แถว 7), แถว “รวม” (แถว 12)
- [ ] คำเตือน 2 แถว: ปีงบประมาณไม่สอดคล้องกับเดือน, ค่าติดลบจาก “(1,234.00)”
- [ ] แถวที่ประเภทบริการว่างถูกบันทึกเป็น “ไม่ระบุประเภทบริการ”
- [ ] แถวว่าง 1 แถวแสดงในสถิติ “แถวว่างที่ข้าม”
- [ ] ปุ่ม “ยืนยันการนำเข้า” กดไม่ได้จนกว่าจะติ๊กรับทราบแถวที่ไม่ผ่าน
- [ ] ผลนำเข้า: รับ 9 · เพิ่มใหม่ 4 · ไม่ผ่าน 5 · Export รายการที่ไม่ผ่านเป็น CSV ได้
- [ ] ไฟล์ที่ขาด Header (ลบคอลัมน์ “เดือน”) → แจ้ง Header ที่ขาดและไม่แสดงขั้นตอนนำเข้า
- [ ] ไฟล์ .txt / ไฟล์เกิน 10 MB → แจ้งไม่รองรับ
- [ ] ใส่ `=HYPERLINK("http://x")` ในประเภทบริการ → ข้อความถูกบันทึกโดยตัด `=` ออก ไม่กลายเป็นสูตรในชีต
- [ ] ใส่ `<script>alert(1)</script>` ในชื่อผู้สมัคร → ถูกปฏิเสธ (VALIDATION_ERROR) และไม่มี popup

## 8. Dashboard

- [ ] ตัวเลือกปีงบประมาณ / เดือน / งวด STM / ประเภทบริการ มาจากข้อมูลจริง (เพิ่มปีใหม่แล้วตัวเลือกเพิ่มเอง)
- [ ] เลือกหลายรายการได้ · ค้นหาในตัวเลือกได้ · “ล้างตัวกรอง” กลับค่าเริ่มต้น
- [ ] ปีหลัก = ปีล่าสุด เทียบกับปีก่อนหน้าโดยอัตโนมัติ · KPI แสดงลูกศร + % + ผลต่าง
- [ ] เลือก “ไม่ใช้โหมดเปรียบเทียบ” → KPI แจ้ง “เลือกปีเปรียบเทียบเพื่อดูการเปลี่ยนแปลง”
- [ ] CMI = Adj.RW รวม ÷ จำนวนบริการ และรายได้เฉลี่ยต่อครั้ง ตรงกับการคำนวณด้วย Excel
- [ ] ทุกกราฟเปลี่ยนตามตัวกรอง · Tooltip ภาษาไทยพร้อมหน่วย · Top 5/10/ทั้งหมด ทำงาน · กราฟ Scatter สลับสเกลลอการิทึมได้
- [ ] ตาราง: Sort ทุกคอลัมน์ · Search · Pagination · ซ่อน/แสดงคอลัมน์ · Export CSV (เปิดใน Excel ภาษาไทยไม่เพี้ยน) · Export Excel · แถวรวมถูกต้อง
- [ ] “ข้อมูลที่น่าสนใจ” อ้างอิงตัวเลขที่ตรงกับ KPI/ตาราง และแสดง “ยังไม่มีข้อมูลเพียงพอ” เมื่อกรองจนไม่มีข้อมูล
- [ ] วันที่ปรับปรุงข้อมูลล่าสุดเปลี่ยนหลังนำเข้า/แก้ไข
- [ ] ตัดอินเทอร์เน็ตแล้วโหลดใหม่ → เห็นข้อความ “ไม่สามารถโหลดข้อมูลได้” พร้อมปุ่มลองใหม่
