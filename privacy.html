IP.UC Performance Analytics Dashboard — ระบบวิเคราะห์ผลงานบริการผู้ป่วยในสิทธิ UC โรงพยาบาลแม่สะเรียง

มีผลบังคับใช้ตั้งแต่วันที่ 12 กันยายน 2569 · ผู้รับผิดชอบ: ศูนย์รายได้ โรงพยาบาลแม่สะเรียง

1. ขอบเขต

นโยบายนี้อธิบายการเก็บ ใช้ และคุ้มครองข้อมูลส่วนบุคคลของผู้ใช้งานระบบ IP.UC Performance Analytics Dashboard (https://tvpwork-dotcom.github.io/ipuc-dashboard/) ซึ่งเป็นระบบภายในสำหรับติดตามผลงานบริการผู้ป่วยในสิทธิ UC ของโรงพยาบาลแม่สะเรียง

2. ข้อมูลที่เก็บ

  • ข้อมูลจากบัญชี Google — อีเมลที่ Google ยืนยันแล้ว เพื่อใช้ยืนยันตัวตนเมื่อเข้าสู่ระบบ ระบบขอเฉพาะสิทธิ์พื้นฐาน (openid, email, profile) และไม่เข้าถึง Gmail, Google Drive, รายชื่อติดต่อ หรือข้อมูลอื่นในบัญชี Google
  • ข้อมูลที่ผู้ใช้กรอกเมื่อสมัคร — ชื่อ และนามสกุล
  • ข้อมูลบัญชีในระบบ — สิทธิ์การใช้งาน สถานะการอนุมัติ วันที่สมัคร วันที่อนุมัติ และวันเวลาเข้าใช้งานล่าสุด
  • บันทึกการใช้งาน (Audit Logs) — วันเวลา อีเมล เหตุการณ์ที่ทำ (เช่น เข้าสู่ระบบ นำเข้า แก้ไข ลบข้อมูล) ค่าก่อนและหลังการแก้ไข และข้อมูลเบราว์เซอร์ (User Agent)
  • ข้อมูลผลงานบริการ — ข้อมูลสรุประดับประเภทบริการจากรายงาน STM (จำนวนบริการ Adj.RW และค่าชดเชย) ไม่มีข้อมูลรายบุคคลของผู้ป่วย เช่น ชื่อ HN หรือเลขประจำตัวประชาชน

ระบบไม่เก็บรหัสผ่านของผู้ใช้ และไม่ใช้คุกกี้เพื่อการโฆษณาหรือติดตามพฤติกรรม เบราว์เซอร์จะเก็บ Session Token และธีมที่เลือกไว้ใน Local Storage ของเครื่องผู้ใช้เท่านั้น

3. วัตถุประสงค์การใช้ข้อมูล

  • ยืนยันตัวตน และควบคุมสิทธิ์การเข้าถึงตามบทบาทของผู้ใช้
  • ให้ผู้ดูแลระบบพิจารณาอนุมัติ ระงับ หรือเปลี่ยนสิทธิ์ผู้ใช้
  • ตรวจสอบย้อนหลังการนำเข้าและแก้ไขข้อมูล เพื่อความถูกต้องและความปลอดภัยของระบบ
  • จัดทำรายงานวิเคราะห์ผลงานบริการสำหรับผู้บริหารโรงพยาบาล

การใช้ข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

4. การจัดเก็บและการเปิดเผยข้อมูล

  • ข้อมูลจัดเก็บใน Google Sheets และประมวลผลผ่าน Google Apps Script ภายใต้บัญชีที่โรงพยาบาลดูแล การรับส่งข้อมูลเข้ารหัสด้วย HTTPS
  • ผู้ที่เข้าถึงข้อมูลบัญชีผู้ใช้และบันทึกการใช้งานได้ คือผู้ดูแลระบบ (ADMIN / SUPER_ADMIN) ที่ได้รับมอบหมายเท่านั้น
  • ไม่ขาย ไม่ให้เช่า และไม่เปิดเผยข้อมูลส่วนบุคคลแก่บุคคลภายนอก เว้นแต่เป็นไปตามที่กฎหมายกำหนด

5. ระยะเวลาการเก็บรักษา

ข้อมูลบัญชีผู้ใช้เก็บไว้ตลอดระยะเวลาที่ยังมีสิทธิ์ใช้งานระบบ บันทึกการใช้งานเก็บไว้ตามความจำเป็นในการตรวจสอบของหน่วยงาน เมื่อพ้นความจำเป็นจะลบหรือย้ายไปเก็บถาวรตามระเบียบของโรงพยาบาล

6. สิทธิของผู้ใช้

ผู้ใช้มีสิทธิขอเข้าถึง แก้ไข หรือขอยกเลิกบัญชีและลบข้อมูลส่วนบุคคลของตน ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 โดยติดต่อศูนย์รายได้ โรงพยาบาลแม่สะเรียง และสามารถถอนสิทธิ์การเข้าถึงบัญชี Google ของระบบนี้ได้ด้วยตนเองที่ การเชื่อมต่อกับแอปและบริการของบัญชี Google

7. การเปลี่ยนแปลงนโยบาย

หากมีการแก้ไขนโยบายนี้ จะปรับปรุงวันที่มีผลบังคับใช้ไว้ด้านบนของหน้านี้
